# Lesson Core Model: "Talking About the Increase of Pornography Use in Our World"

*Shared scaffolding — never taught directly to any age group.*

## Why only one band exists (for now)

No 5-8, 8-11, or 11-14 version has been built. This content needs to not be translated downward, or
adapted very carefully — the developmental and safeguarding considerations are significant enough
that an 11-14 version should only be attempted with input from a child-safeguarding or
family-therapy professional, not extrapolated from the existing content-adaptation pattern alone.

A 21+ version hasn't been built either, though the existing content already reads largely
age-neutral (identity-first, shame-reduction framing rather than anything school-specific) — it
likely serves a college/adult audience close to as-is, and differentiating it further is a
light-edit job rather than a rebuild whenever there's time for it.
